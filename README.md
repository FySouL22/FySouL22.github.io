# Ft7y.Sec — موقع محمد فتحي

موقع شخصي ثابت لعرض مجالات العمل في الأمن السيبراني، المشاريع، أدوات Python، وتقارير CTF. رابط النشر: [fysoul22.github.io/ft7.cv.github.io](https://fysoul22.github.io/ft7.cv.github.io/).

## الترخيص

المستودع مرخّص بموجب MIT؛ راجع ملف [`LICENSE`](LICENSE). وتُطبّق الرخصة على الملفات التي يملك المؤلف حق ترخيصها.

## خريطة المشروع

- `index.html`: الصفحة الرئيسية، النبذة، المهارات، المشاريع والتواصل.
- `style.css`: متغيرات الألوان والتنسيق المشترك لكل الصفحات.
- `script.js`: تفاعلات الصفحة والحركات.
- `assets/js/market-ticker.js`: شريط الأسعار، جلب البيانات وتخزين آخر استجابة ناجحة.
- `writeups.html` و`ctfs/`: فهرس وتقارير تحديات CTF.
- صفحات الجذر الأخرى: المشاريع، الأدوات، الأبحاث، المعامل والمراجع.
- `assets/images/ctfs/`: صور التقارير؛ استخدم صورًا مضغوطة وأضف نصًا بديلًا وصفيًا.
- `robots.txt` و`sitemap.xml` و`.well-known/security.txt`: إعدادات الفهرسة والتواصل الأمني.
- `.github/workflows/`: فحوص الجودة والأمان والأداء.

## التعديل محليًا

1. عدّل الملفات المصدرية مباشرة في المستودع.
2. لمعاينة الصفحات، شغّل خادم ملفات محليًا من مجلد المشروع: `python -m http.server 8000`.
3. افتح `http://localhost:8000/`، وتحقق من العرض على شاشة صغيرة، ومن تعطيل الحركة عبر إعدادات النظام.
4. قبل الدمج، راجع فحوص GitHub Actions وسجّل صور CTF في مجلد `assets/images/ctfs/` مع مسارات نسبية صحيحة.

لا توجد خطوة بناء أو حزم npm مطلوبة؛ صفحات HTML/CSS/JS تُنشر كما هي عبر GitHub Pages.

## شريط الأسعار

يعرض الشريط BTC وETH وSOL وBNB وXMR مقابل USDT من واجهة Binance العامة، ويعرض قيمة جنيه مصري واحد بالدولار عبر مقلوب سعر USD/EGP من ExchangeRate.fun. أسعار أزواج USDT تقريبية بالدولار وليست أسعار USD مباشرة. تُحفظ آخر البيانات محليًا في المتصفح وتُعرض قبل التحديث، ولا يُطلب السعر مجددًا إلا عند تقادم بيانات المصدر أو مرور ساعة. عند تعذر أحد المصدرين تبقى بياناته المحفوظة ظاهرة مع توضيح حالة التحديث.

الأيقونات ملفات SVG محلية صغيرة ضمن `assets/images/market/`، مرسومة لهذه الواجهة بأشكال مبسطة للتعريف بالعملات. لا تُحمّل الأيقونات من مواقع خارجية ولا توحي برعاية أو شراكة. روابط [أصول Ethereum](https://ethereum.org/assets)، و[إرشادات Solana](https://solana.com/branding)، و[حزمة Monero الصحفية](https://www.getmonero.org/press-kit/)، و[إرشادات BNB Chain](https://www.bnbchain.org/en/brand-guidelines)، و[الدليل المرئي لـ Bitcoin Design](https://bitcoin.design/guide/getting-started/visual-language/) مراجع للأشكال واستخدام العلامات.
