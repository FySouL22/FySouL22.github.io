الأنظمة والمعامل الأمنية (Systems, Hardening & HomeLabs)

دليل معماري وعملي متكامل لتأسيس بيئات ومعامل الاختراق المنزلية (HomeLabs)، تأمين أنظمة Linux ومسارات تصعيد الصلاحيات، بناء شبكات Active Directory لمحاكاة هجمات المؤسسات، تأمين حاويات Docker، وتنصيب معمل مراقبة أمنية SOC / SIEM عبر Wazuh، مع خارطة طريق تدريبية لاحتراف منصات TryHackMe و HackTheBox.

1. معمل Active Directory المؤسسي المنزلي (Home AD Lab)

بناء بيئة تحاكي شبكات الشركات لاختبار هجمات Kerberos واكتشاف مسارات السيطرة على الدومين (Domain Compromise) وطرق التقسية والدفاع.

المخطط المعماري للأجهزة في المعمل المعزول (Subnet: 192.168.10.0/24):

Domain Controller (DC01)

OS: Windows Server 2022
IP: 192.168.10.10
Role: Active Directory, DNS, Kerberos KDC, Certificate Authority

Workstation 01 (WS01)

OS: Windows 10/11 Enterprise
IP: 192.168.10.20
Role: Domain-joined Client, Simulated User Activity, SQL Server

Attacker Machine

OS: Kali Linux
IP: 192.168.10.50
Tools: Impacket, BloodHound, NetExec, Responder, Mimikatz

أشهر هجمات الـ Active Directory المحاكاة في المعمل
Kerberoasting: طلب تذاكر TGS لحسابات الـ SPNs المشفرة بكلمات مرور وكسرها بدون اتصال. AS-REP Roasting: استهداف الحسابات التي لا تتطلب مصادقة Kerberos المسبقة واستخراج تجزئتها فوراً. BloodHound Analysis: تشغيل SharpHound لرسم العلاقات واكتشاف مسار تصعيد الصلاحيات إلى Domain Admin. Pass-the-Hash (PtH): استخدام تجزئة NTLM المسحوبة من الذاكرة لتنفيذ أوامر عن بعد عبر SMB/WMI دون معرفة كلمة السر. DCSync: انتحال صفة Domain Controller ثانٍ وسحب كافة تجزئات النطاق (بما فيها حساب krbtgt).
أمر Impacket العملي لهجوم Kerberoasting داخل المعمل
impacket-GetUserSPNs lab.local/user:Password123 -dc-ip 192.168.10.10 -request -outputfile hashes.kerberoast
كسر التجزئات الناتجة عبر Hashcat: hashcat -m 13100 -a 0 hashes.kerberoast rockyou.txt

2. تأمين أنظمة Linux وتصعيد الصلاحيات (Linux Hardening & PrivEsc)

استكشاف أشهر نقاط الضعف التي تتيح للمخترق القفز من مستخدم عادي إلى صلاحيات Root، مع قائمة التحقق العملية لحماية وتأمين الخوادم.

فحص واستخراج ملفات الـ SUID الخطيرة القابلة للاستغلال عبر GTFOBins
find / -perm -u=s -type f 2>/dev/null
ملفات مشبوهة إذا وُجدت بـ SUID: /usr/bin/find, /usr/bin/vim, /usr/bin/python3, /usr/bin/bash
تشغيل سكربت التدقيق التلقائي LinPEAS مباشرة في الذاكرة دون ترك أثر
curl -L https://github.com/carlospolop/PEASS-ng/releases/latest/download/linpeas.sh | sh
يقوم بفحص إصدار الكيرنل، ملفات Cron، كلمات المرور المخزنة، وصلاحيات Sudo
إجراءات التقسية الأساسية لخوادم الإنتاج (Hardening Checklist)
  • تأمين خدمة SSH: تعديل /etc/ssh/sshd_config لمنع تسجيل الدخول كـ Root (PermitRootLogin no)، وتعطيل كلمات المرور والاعتماد على مفاتيح SSH فقط (PasswordAuthentication no).
  • جدار الحماية UFW: إغلاق كافة المنافذ افتراضياً وفتح المنافذ الضرورية فقط (ufw default deny incoming; ufw allow 22/tcp; ufw enable).
  • الحماية من التخمين: تنصيب أداة fail2ban لحظر أي عنوان IP يتكرر فشله في تسجيل الدخول تلقائياً.
  • التدقيق الأمني الدوري: تشغيل فاحص الأنظمة الشهير Lynis عبر الأمر sudo lynis audit system لتوليد تقرير التقسية.

3. أمن الحاويات والـ Docker (Container Security & Escapes)

تأمين صور الحاويات، تفادي سيناريوهات الهروب للنظام المضيف (Container Escapes)، وفحص الثغرات في طبقات Dockerfile.

خطر تمرير Docker Socket وكيف يؤدي إلى السيطرة الكاملة على السيرفر المضيف
docker run -it -v /var/run/docker.sock:/var/run/docker.sock alpine sh
تحذير أمني: يتيح لمن بداخل الحاوية إنشاء حاوية جديدة بـ --privileged وقراءة قرص الخادم المضيف بالكامل.
فحص صورة Docker واكتشاف الثغرات في الحزم والمكتبات عبر Trivy
trivy image --severity HIGH,CRITICAL python:3.11-alpine
استخراج تقرير بجميع CVEs ومستوى خطورتها ورقم الإصدار الذي تم فيه ترقيع الثغرة.
أفضل الممارسات لكتابة Dockerfile آمن ومنيع (Best Practices)
Dockerfile (Hardened) 
FROM python:3.11-slim
# 1. Don't run as root! Create a non-privileged system user
RUN groupadd -r appuser && useradd -r -g appuser -d /app appuser
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
# 2. Change ownership to the non-root user
USER appuser
# 3. Read-only root filesystem when executed
EXPOSE 8000
CMD ["python", "app.py"]

4. بيئات المحاكاة الافتراضية وعزل شبكات المعمل (Virtualization)

مقارنة بين منصات VirtualBox, VMware, Proxmox VE وكيفية إعداد جدار حماية وهمي مثل pfSense كبوابة آمنة للمختبر.

Type-2: VMware / VirtualBox

يعمل فوق نظام التشغيل المكتبي (Windows أو Linux). مثالي للبداية والتدريب الفردي.

إعداد الشبكة: استخدم وضع Host-Only أو Internal Network لعزل أجهزة الضحايا عن شبكة منزلك تماماً.

Type-1: Proxmox VE Hypervisor

نظام تشغيل مخصص للسيرفرات (Bare-metal) يدعم KVM و LXC Containers وواجهة ويب ممتازة.

الميزة: يعمل على مدار الساعة لاستهلاك طاقة منخفض، ويوفر أخذ لقطات فورية (Snapshots) عند كسر الأجهزة.

pfSense / OPNsense Router

جدار حماية وراوتر وهمي مفتوح المصدر يُنصب داخل المعمل للفصل بين شبكة المهاجم وشبكة الضحايا.

التحكم: مراقبة حزم البيانات، منع وصول الأجهزة المصابة للإنترنت الخارجي، وتخصيص VLANs منفصلة.

5. معمل المراقبة وتحليل التهديدات (SOC & Wazuh SIEM Lab)

بناء معمل Blue Team مفتوح المصدر لتجميع سجلات الأحداث من أجهزة الويندوز واللينكس واكتشاف الهجمات فورياً عبر محرك القواعد و Sysmon.

تشغيل سيرفر Wazuh SIEM المتكامل بكامل خدماته في دقائق عبر Docker Compose
git clone https://github.com/wazuh/wazuh-docker.git -b v4.8.0 && cd wazuh-docker/single-node && docker compose up -d
لوحة التحكم متاحة عبر: https://<wazuh-ip> بالحساب الافتراضي: admin / admin
تنصيب Microsoft Sysmon على أجهزة Windows لمراقبة إنشاء العمليات وحقن الذاكرة
sysmon.exe -accepteula -i sysmonconfig.xml
تطبيق إعدادات SwiftOnSecurity الشهيرة لتسجيل عمليات حقن الذاكرة ومحاولات استخراج كلمات المرور.

6. خارطة طريق منصات التدريب العالمية (CTF Platforms Roadmap)

مسارات وتوجيهات عملية للانتقال من مرحلة الأساسيات حتى الوصول لمستوى الاحتراف في منصات TryHackMe و HackTheBox و PortSwigger.

TryHackMe المرتبة الأولى للمبتدئين

المسارات التعليمية الموصى بها

  • Pre-Security: استيعاب مبادئ الشبكات، بروتوكولات الويب، وأساسيات Linux.
  • Jr Penetration Tester: تعلم المنهجية الرسمية لاختبار الاختراق، ثغرات OWASP، وفحص Nmap و Burp.
  • الغرف التكتيكية المفضلة: Mr Robot, Blue, Kenobi, Steel Mountain, Buffer Overflow Prep.
HackTheBox بيئة واقعية ومتقدمة

خطة التقدم على HTB

  • Starting Point: اجتياز Tiers (0, 1, 2) لفهم التعامل مع المنافذ والـ Shells.
  • Easy Linux Machines: حل آلات كلاسيكية مثل Lame, Bashed, Shocker, Beep.
  • Easy Windows Machines: البدء بـ Blue, Devel, Jerry, ثم آلات الـ Active Directory مثل Forest و Active.
PortSwigger Academy أمن تطبيقات الويب

معامل مجانية لاختبار ثغرات الويب

  • أفضل منصة في العالم للتدريب على ثغرات الويب بدون أي اشتراك.
  • حل المعامل بالتدرج: مستوى Apprentice ثم Practitioner.
  • المواضيع الأساسية: SQL Injection, XSS, CSRF, Clickjacking, SSRF, Access Control.
