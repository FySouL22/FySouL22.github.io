فاحص منافذ متعدد الخيوط فائق السرعة (Fast Port Scanner)

سكربت بايثون 3 يعتمد على مقابس الشبكة socket ووحدة concurrent.futures لفحص مئات المنافذ في ثوان معدودة والتقاط عنوان الخدمة (Banner Grabbing).

port_scanner.py 
import socket
import sys
from concurrent.futures import ThreadPoolExecutor

TARGET_HOST = sys.argv[1] if len(sys.argv) > 1 else "127.0.0.1"
PORTS_TO_SCAN = range(1, 1025)  # Well-known ports
TIMEOUT = 0.8

def scan_port(port):
    try:
        with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
            s.settimeout(TIMEOUT)
            result = s.connect_ex((TARGET_HOST, port))
            if result == 0:
                # Banner Grabbing attempt
                try:
                    s.sendall(b"HEAD / HTTP/1.0\r\n\r\n")
                    banner = s.recv(1024).decode('utf-8', errors='ignore').split('\r\n')[0]
                except Exception:
                    banner = "Service Active"
                print(f"[+] Port {port:5d}/TCP is OPEN --> {banner}")
    except socket.error:
        pass

print(f"[*] Starting Multi-threaded Scan on: {TARGET_HOST}")
with ThreadPoolExecutor(max_workers=100) as executor:
    executor.map(scan_port, PORTS_TO_SCAN)
print("[*] Scan completed successfully.")

فاحص دلائل الويب التلقائي (Web Directory Brute-Forcer)

أداة بايثون ترسل طلبات HTTP متوازية لاكتشاف الملفات الحساسة ولوحات التحكم المخفية مع فلترة رموز الاستجابة (200, 301, 403).

web_fuzzer.py 
import requests
from concurrent.futures import ThreadPoolExecutor

BASE_URL = "https://example.com"
WORDLIST_PATH = "common_dirs.txt"
HEADERS = {"User-Agent": "Ft7y-Sec-Custom-Fuzzer/1.0"}

def check_endpoint(word):
    word = word.strip()
    if not word or word.startswith("#"):
        return
    url = f"{BASE_URL}/{word}"
    try:
        res = requests.get(url, headers=HEADERS, timeout=3, allow_redirects=False)
        if res.status_code in [200, 204, 301, 302, 307, 401, 403]:
            color = "\033[92m" if res.status_code == 200 else "\033[93m"
            print(f"{color}[{res.status_code}] --> {url} (Length: {len(res.content)})\033[0m")
    except requests.RequestException:
        pass

with open(WORDLIST_PATH, "r", encoding="utf-8", errors="ignore") as f:
    words = f.readlines()

print(f"[*] Launching directory discovery on {BASE_URL} ({len(words)} words)...")
with ThreadPoolExecutor(max_workers=40) as pool:
    pool.map(check_endpoint, words)

كاشف هجمات التسمم وتحويل المسار (ARP Spoof Detector with Scapy)

مراقبة حزم الـ ARP في الشبكة المحلية بالزمن الحقيقي وتنبيه المستخدم في حال وجود هجوم Man-in-the-Middle يحاول انتحال عنوان الراوتر.

arp_detector.py 
from scapy.all import sniff, ARP

ip_mac_table = {}

def process_arp_packet(packet):
    if packet.haslayer(ARP) and packet[ARP].op == 2:  # ARP Response/Is-at
        sender_ip = packet[ARP].psrc
        sender_mac = packet[ARP].hwsrc.lower()

        if sender_ip in ip_mac_table:
            known_mac = ip_mac_table[sender_ip]
            if known_mac != sender_mac:
                print(f"\033[91m[!] CRITICAL ALERT: Possible ARP Spoofing Detected!\033[0m")
                print(f"    IP: {sender_ip} has CHANGED from [{known_mac}] to [{sender_mac}]")
        else:
            ip_mac_table[sender_ip] = sender_mac
            print(f"[*] New Host Logged: {sender_ip:15s} -> {sender_mac}")

print("[*] Sniffing for ARP anomaly on local network interface...")
sniff(filter="arp", store=0, prn=process_arp_packet)

ون-لاينر الاستطلاع التلقائي المتكامل (Recon Automation Pipeline)

سلسلة أوامر متصلة لجمع النطاقات الفرعية، التحقق من المواقع النشطة، وفحص الثغرات الحرجة آلياً عبر دمج الأدوات الرائدة.

recon_pipeline.sh 
#!/bin/bash
TARGET=$1
if [ -z "$TARGET" ]; then
    echo "Usage: ./recon_pipeline.sh domain.com"
    exit 1
fi

mkdir -p "recon_${TARGET}"
echo "[*] Step 1: Enumerating subdomains..."
subfinder -d "$TARGET" -silent | sort -u > "recon_${TARGET}/subs.txt"

echo "[*] Step 2: Probing live web endpoints..."
httpx -l "recon_${TARGET}/subs.txt" -silent -status-code -title -tech-detect -o "recon_${TARGET}/live_hosts.txt"

echo "[*] Step 3: Scanning for critical vulnerabilities with Nuclei..."
cat "recon_${TARGET}/live_hosts.txt" | awk '{print $1}' | nuclei -t cves/,vulnerabilities/ -severity critical,high -o "recon_${TARGET}/nuclei_alerts.txt"

echo "[+] Recon completed! Results stored in recon_${TARGET}/"

استخراج المنافذ المفتوحة من مخرجات Nmap بنقرة واحدة

دالة Bash سريعة تحول مخرجات Nmap (ملف .gnmap) إلى قائمة منافذ مفصولة بفواصل لنسخها وتمريرها في أدوات الفحص التفصيلي.

parse_ports.sh 
# Add this function to your ~/.bashrc or execute directly:
extract_ports() {
    FILE=$1
    if [ ! -f "$FILE" ]; then
        echo "Usage: extract_ports target.gnmap"
        return
    fi
    PORTS=$(grep -oP '\d+/open' "$FILE" | cut -d '/' -f 1 | paste -sd ',' -)
    IP=$(grep -oP 'Host: \K[0-9.]+' "$FILE" | head -n 1)
    echo "[+] Target IP: $IP"
    echo "[+] Open Ports: $PORTS"
    echo "$PORTS" | xclip -selection clipboard 2>/dev/null || true
    echo "[*] Command ready: nmap -p$PORTS -sV -sC $IP"
}

استكشاف دومين Active Directory بدون أدوات خارجية (Native AD Enum)

استخدام كائنات DirectorySearcher المدمجة في Windows لاستخراج مدراء النطاق وأجهزة السيرفرات دون إطلاق إنذارات برامج مكافحة الفيروسات (AV/EDR Evasion).

ad_enum.ps1 
Write-Host "[*] Querying Domain Controllers..." -ForegroundColor Cyan
[System.DirectoryServices.ActiveDirectory.Domain]::GetCurrentDomain().DomainControllers | 
    Select-Object Name, IPAddress, OSVersion

Write-Host "`n[*] Extracting Members of 'Domain Admins'..." -ForegroundColor Yellow
$Searcher = [ADSISearcher]'(samAccountType=805306368)'
$Searcher.Filter = "(&(objectClass=user)(memberOf=*Domain Admins*))"
$Searcher.FindAll() | ForEach-Object {
    [PSCustomObject]@{
        Username     = $_.Properties.samaccountname[0]
        Email        = $_.Properties.mail[0]
        LastLogon    = [DateTime]::FromFileTime($_.Properties.lastlogontimestamp[0])
    }
} | Format-Table -AutoSize

لماذا لغة Go؟ وكيفية تثبيت وإدارة ترسانة الأدوات الأمنية الحديثة

تعتبر Go اللغة المعيارية لأدوات الـ Recon في العصر الحديث بفضل السرعة العالية، انعدام الاعتماديات (Single Static Binary)، ودعم الخيوط المتزامنة الفائق عبر Goroutines.

install_go_arsenal.sh 
#!/bin/bash
# Fast install of the modern Go security arsenal
echo "[*] Installing ProjectDiscovery Tools..."
go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest
go install -v github.com/projectdiscovery/httpx/cmd/httpx@latest
go install -v github.com/projectdiscovery/naabu/v2/cmd/naabu@latest

nuclei -version

خط فحص أمني مؤتمت مع كل Commit (GitHub Actions Security Pipeline)

ملف سير عمل (Workflow) يقوم بفحص الكود عبر Semgrep وفحص حزم الاعتماديات عبر Trivy تلقائياً وإيقاف الـ Merge إذا وجدت ثغرة أمنية عالية الخطورة.

.github/workflows/security-scan.yml 
name: DevSecOps Automated Security Scan

on:
  push:
    branches: [ "main", "dev" ]
  pull_request:
    branches: [ "main" ]

jobs:
  sast_scan:
    name: SAST Code Analysis (Semgrep)
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Run Semgrep SAST
        run: |
          docker run --rm -v "${{ github.workspace }}:/src" returntocorp/semgrep \
            semgrep scan --config=auto --error

  dependency_scan:
    name: SCA Vulnerability Scan (Trivy)
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Scan Dependencies with Trivy
        uses: aquasecurity/trivy-action@master
        with:
          scan-type: 'fs'
          ignore-unfixed: true
          severity: 'CRITICAL,HIGH'
          exit-code: '1' # Break the build if critical flaws exist
